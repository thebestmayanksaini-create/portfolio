# Mayank Saini - Developer Portfolio

A sleek, responsive, and modern personal developer portfolio built with pure **HTML5**, **CSS3**, and **JavaScript**.

## 🚀 Features
- **Dynamic Typing Effect** in the hero section displaying multiple roles.
- **Glassmorphism & Neon Glow** design with smooth ambient lighting.
- **Dark / Light Mode Toggle** with `localStorage` persistence.
- **Interactive Terminal Window** displaying C++ DSA profile code.
- **Comprehensive Sections**:
  - Hero with CTA & Socials
  - Quick Stats Strip (MAIT Delhi, C++ DSA, MERN Stack)
  - About Me & Highlights
  - Technical Arsenal (Languages, Frontend, Backend, Tools & CS fundamentals)
  - Featured Projects with live & GitHub links
  - Education Timeline (MAIT B.Tech 2nd Year, DSA Track)
  - Contact Form with 1-click email copy & direct mail launch
- **Fully Responsive** across phones, tablets, and desktops.

## 📁 File Structure
- `index.html` - The markup and structure
- `style.css` - Custom styling, glassmorphism, responsive grid & themes
- `script.js` - Typing effect, dark mode toggle, copy button & interaction logic

## 🛠️ How to Open & Preview
1. Double-click `index.html` to open it in your browser (Chrome, Edge, Brave, etc.).
2. Or use VS Code extension **Live Server** to preview with hot-reload.

## ✏️ Quick Customizations
- **Resume:** Place your `resume.pdf` in this folder and update `<a href="resume.pdf">` on line 78 in `index.html`.
- **Social Links:** Search for `https://github.com`, `https://linkedin.com`, and `https://leetcode.com` in `index.html` to add your profile handles.
- **Projects:** Update project titles, descriptions, and URLs in the `#projects` section as you build new things!
